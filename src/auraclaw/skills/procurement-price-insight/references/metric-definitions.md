# 价格洞察指标定义 1.0.0

分析粒度为最终成交价格行 `price_line_id`。所有均价均按标准数量加权。

| 指标键 | 名称 | 定义 |
|---|---|---|
| `history_dev_pct` | 历史维偏离 | 当前期成交价相对同可比物料上一可用期加权均价的加权偏离率 |
| `region_gap_max` | 区域维价差 | 可比组内最高区域加权均价相对最低区域加权均价的最大差异 |
| `market_dev_pct` | 市场维偏离 | 已选行业基准下，成交价相对声明统计口径行业均价的加权偏离率 |
| `impact_amount` | 正偏移金额 | `max(0, 成交价 - 对标价) × 标准数量` 的合计 |
| `impact_neg_amount` | 负偏移金额 | `max(0, 对标价 - 成交价) × 标准数量` 的合计 |
| `impact_share_pct` | 正偏移占采购额 | 正偏移金额 / 当前采购金额 |
| `impact_neg_share_pct` | 负偏移占采购额 | 负偏移金额 / 当前采购金额 |
| `deviation_cnt` | 市场偏离行 | 市场偏离绝对值达到筛选阈值的成交价格行数 |

三类锚点独立计算影响金额：`history`、`region`、`market`。正负影响分别汇总，不做净额抵消。
