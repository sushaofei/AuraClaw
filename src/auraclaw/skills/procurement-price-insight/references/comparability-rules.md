# 价格可比规则 1.0.0

可比键至少包含：标准物料（或受治理的源物料）、规格型号、标准单位、币种、含税/未税口径。

- 历史对标：同一可比键使用上一可用月份，不跨越口径变化。
- 区域对标：同一可比键至少覆盖两个区域，基准为组内数量加权均价。
- 市场对标：只使用 `is_selected=true` 且状态为 `MATCHED`、`SELECTED` 或 `COMPARABLE` 的基准。
- 行业基准必须声明 `benchmark_version`、`rule_version` 和统计类型，不能把均值、P50 混用。
- 缺少标准单位、物料映射、基准价格或存在孤儿关联时，必须暴露数据质量问题。
- 所有数据访问必须由租户条件约束；Skill 不接收原始 SQL、表名或连接凭据。
