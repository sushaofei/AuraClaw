# 业务语义查询

使用已授权的语义工具回答业务问数，口径以服务端模型为准。

1. 调用 `auramcp.semantic.discover` 找到数据集，再调用 `auramcp.semantic.describe`。
2. 阅读指标定义、单位、时间字段与时区；选择真实存在的指标和维度。遇到业务歧义先澄清。
3. 使用返回的 `model_version` 构造 `auramcp.semantic.query`。不传 SQL、连接地址、身份或凭据。
4. 时间输入是模型时区的当地时间，start 包含、end_exclusive 不包含。公告时间与入库时间不能混用。
5. 行数限制只限制分组结果，不限制聚合输入。用户指定记录子集时必须加入对应筛选，不能把 limit 当样本范围。
6. 完成后报告实际范围、指标单位、口径与结果。金额保持原单位，缺失值不是零；记录数不等于去重项目数。
7. 保留截断与新鲜度信息。查询完成时间不代表业务数据截止时间；data_as_of 未知时明确未知。
8. MODEL_CHANGED 时重新 describe 并核对口径；ACCESS_DENIED 时停止，不改用 database 工具绕过权限；超时只在明确缩小范围后重试一次。
9. 不更改模型、权限或业务数据，不执行全库探索来猜测模型没有提供的口径。
