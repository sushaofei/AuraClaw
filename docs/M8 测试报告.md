## 真实基础设施与模型冒烟

- Kafka 集成测试完成 `KafkaRuntimeEventProducer → Topic → KafkaStreamingIngestor →
  ReplayRuntimeEventBus` round-trip，并验证公开 Session sequence。
- PostgreSQL 集成覆盖 Event/Outbox、Control lease/fencing/checkpoint、Projection、Delivery 与
  Observability。
- gitignored 本地 `.env` 的旧厂商键已机械迁移为通用键，值未读取、回显或提交。
- 真实 OpenAI-compatible 端点使用配置模型 `glm-5.2` 完成最小流式调用：1 个 content delta、
  `finish_reason=stop`，并返回 input/output/total token usage。测试输出未包含回答正文或凭证。
- 当前环境使用 SOCKS 代理；项目已锁定 `socksio==1.0.0`，生产 Adapter 可遵循标准代理环境。

## 边界与后续

- Runtime Worker 当前与 API 同进程部署，保持 Orchestrator、Harness、Gateway 与 Store 的
  逻辑边界；独立多进程 `runtime run` 留给后续 issue。
- 不包含 Vault/KMS、动态租户凭证、多模型策略、fallback、embed/cancel 或 Prompt Cache。
- Runtime Event 故障只降低实时流和 readiness，不阻止完整输出及 `run.completed` 写入
  Canonical Event。
