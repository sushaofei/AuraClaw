## M4 覆盖范围

- 串行 DAG：依赖完成前后 blocked/runnable 转换正确。
- 并行 DAG：多个无依赖 Child 同时 runnable，并发发布结果互不修改 Root。
- 树形 DAG：Child 可继续分解，parent、depth 与 lineage 保留。
- 混合 DAG：并行前置 Child 汇合后解锁后继 Child。
- Coordinator 使用稳定 `task_key` 重试或重启时不会重复创建 Child。
- DAG 拒绝环、自依赖、跨 Root/tenant 依赖，并限制深度、单父宽度、Child 总数与预算。
- Worker Result 在进入 completed 前必须满足版本化 Output Contract。
- Worker 不能写 Root；非 Owner Worker 不能发布其他 Child Result。
- Reviewer 使用独立 Session，只能发布包含 evidence refs 的三态决策，不能覆盖 Worker Artifact。
- Join 只接受已完成 Child 和 accepted Review，并生成 Child Result、Review 与 Artifact lineage。
- Collaboration Projection 可从 Canonical Event Log 清空重建，并计算 runnable Child。
- PostgreSQL `projection.collaboration_view` 的写入、查询与重建在真实测试库通过。

## 已知边界

- 当前提供确定性的协作命令层和 Coordinator/Worker/Reviewer 角色 facade；具体模型驱动的复杂度
  判断、语义拆分 Prompt 和动态修复策略由 Model Gateway 上层策略按合同接入。
- M4 不包含 M5 的 SSE 重放与可靠 Result Delivery，也不把 Runtime Event Bus 当作结果保证。
