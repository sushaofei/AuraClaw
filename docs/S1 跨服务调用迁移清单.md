# S1 跨服务调用迁移清单

本清单记录 S1 建立稳定契约后仍由 development combined profile 使用的进程内调用。
S1 不提前删除这些兼容适配器；S2 为它们提供独立入口，S3 删除非 owner 服务的数据库
凭证和直连装配。

## Session / Event Store

| 调用方 | 当前直连 | S1 目标 Port | S3 迁移动作 |
|---|---|---|---|
| Task API | `TaskService -> EventStore` | `SessionAppendRequest` / Session Internal API | Task API 仅装配 Session HTTP client；保留 user Actor，并由 workload identity 约束事件 allowlist |
| Agent Runtime | `FencedSessionClient -> EventStore + ControlStateStore` | Session append/feed + signed `LeaseAssertion` | Runtime 删除 Event/Control Store 凭证，重试保持 command id，Session 持久化 fencing high-water mark |
| Orchestrator | `ManagedOrchestrator -> SessionClient` 的 in-process adapter | Session append + orchestrator allowlist | 改装配 Session HTTP client，不得伪造 Runtime Actor |
| Delivery | `ResultDeliveryWorker -> EventStore` | Session append + delivery allowlist | Delivery 只追加 delivery 事件；Outbox 经 claim/ack/nack/poison API 消费 |
| Parent Session delivery | `ParentSessionSink -> EventStore` | Session append | 父 Session 写入经 Session API，保持原 command id 和 expected version |
| Projection | `OutboxRelay -> EventStore` | Outbox claim/disposition + event feed | Projection 删除 Session schema 更新权限 |
| Projection rebuild | `ProjectionMaintenanceService -> load_all` | owner Admin API + rebuild feed | CLI 改调 Projection Admin API，不直接连接 Session/Projection schema |

## Control / Runtime

| 调用方 | 当前直连 | S1 目标 Port | S3 迁移动作 |
|---|---|---|---|
| Runtime Harness | `ControlStateStore` checkpoint/cancel/fencing | Control Internal API | 只装配 Control HTTP client；Checkpoint 携带 lease assertion |
| Runtime Worker | 扫描 Event Store 查 runnable | Assignment claim/heartbeat | 改消费 Orchestrator assignment，不扫描 Event Log |
| Orchestrator | `ControlStateStore` | owner 内部 Port | 仍由 Orchestrator 进程内调用，成为唯一 Control Store 写入者 |

## Model / Hands / Policy / Credential / Artifact

| 调用方 | 当前直连 | S1 目标 Port | S3 迁移动作 |
|---|---|---|---|
| Runtime | 进程内 `ModelGateway` | Model generate/stream/cancel HTTP contract | Runtime 配置只含 Gateway URL 和 workload token，不含 Provider Secret |
| Runtime | `FencedToolClient` / `GatewayToolClient` | MCP 2025-11-25 `/mcp` | Runtime 仅装配 `HandsMcpClient`，删除 Tool handler/Sandbox 依赖 |
| Hands | 进程内 `PolicyEngine` | Policy evaluate/approval HTTP contract | Policy 不可用时写入、外发、凭证操作 fail closed |
| Hands / Delivery | 进程内 `CredentialProxy` | invoke/sign/initialize/revoke HTTP contract | 真实 Secret 只存在于 Credential Proxy/Vault 信任域 |
| Runtime / Hands / Delivery | 进程内 `ArtifactStore` | createUpload/finalize/download HTTP contract | 只由 Artifact Service 获得 SeaweedFS 凭证；调用方只持 artifact ref/短期 URL |
| Operations | `PostgresOperationsStore` 跨域操作 | owner `AdminOperationRequest` | rebuild/redrive/retention/DLQ 转发给相应 owner 服务 |

## 兼容与回滚

- `auraclaw serve` 在 S1 继续使用 in-process contract adapter，公开 `/v1/*` 不变。
- HTTP 与 in-process adapter 运行同一组请求/响应模型测试；切换仅发生在 composition。
- MCP JSON-RPC request id 只用于协议关联，`tool_invocation_id` 继续作为业务幂等键。
- S2/S3 迁移采用逐调用方切换；失败时可回滚 composition，但不得放宽事件 allowlist、
  Lease/Fencing 校验或将 Secret 注入 Runtime。
