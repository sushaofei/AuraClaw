# M3 测试报告：工具、Artifact 与审批安全闭环

## 结论

M3 功能、架构与安全验收通过。Tool Call 已形成 Registry/Schema/Policy/Approval、Hands 或
Credential Proxy、Result Redaction/Normalization、Artifact Reference 的受控闭环。Canonical
Session Event 仍是审批与任务状态的唯一事实源，Approval Projection 可重建。

最终门禁：Ruff 通过；Mypy strict 通过（42 个源码文件）；Pytest 通过（31 项）。

## 测试环境

- Python：项目 `uv` 环境，支持 Python 3.11+。
- 存储：内存适配器与开发 PostgreSQL。
- 入口：领域/应用单元测试、Runtime 恢复测试、FastAPI TestClient、PostgreSQL 集成测试。
- 数据：每项测试使用独立 tenant、Session、Run、Approval 和 Artifact 标识；不使用真实凭证。

## 验收用例

| 领域 | 用例 | 预期与结果 |
|---|---|---|
| Registry / Schema | 非法字段、缺失字段、错误类型 | 在 Hands 前拒绝；通过 |
| 权限 | suggest-only、write-with-approval、destructive/admin | deny 或 require approval；通过 |
| Action Digest | 批准后修改 target 参数 | digest mismatch，旧审批不可复用；通过 |
| 审批入口 | Human 经 Task Gateway 提交 approved/rejected | 鉴权、幂等、expected version、Canonical Event；通过 |
| 审批恢复 | Runtime 首次遇到 approval_required，批准后重入 | 首次不写 run.completed，恢复后工具与 run 各完成一次；通过 |
| 工具幂等 | 相同 tenant/key 并发调用两次 | Hands 仅执行一次；通过 |
| 幂等冲突 | 同一 key 对应不同 action digest | 拒绝且不产生第二次副作用；通过 |
| 取消 | 取消长时间 Hands 调用 | 返回 cancelled，状态可查询；通过 |
| Sandbox | `../../etc/passwd` 路径逃逸 | sandbox_violation；通过 |
| Process 环境 | 运行受控 `env` | 只有固定最小环境，不含 Vault Secret；通过 |
| Credential Scope | tenant、operation、expiry、revocation | 越权 fail closed；通过 |
| Secret 脱敏 | 外部响应回显 Bearer 与原始 Token | Tool Result 中全部替换为 `[REDACTED]`；通过 |
| 大型结果 | Tool 返回超过 inline limit 的 JSON | Session 侧只见 artifact_ref；通过 |
| Artifact ACL | 跨 tenant 或 actor 使用下载 token | artifact_access_denied；通过 |
| Artifact 版本 | 派生新内容 | 新不可变 artifact_id/version 并记录 lineage；通过 |
| PostgreSQL | Approval requested/approved 投影与重复事件 | 幂等更新，可按 digest 查询；通过 |
| 回归 | M0～M2 全量测试 | 通过；未改变事实源、Outbox、Lease/Fencing 语义 |

## 安全证据

- 真实 Secret 只由 Vault 返回给 Credential Proxy 内部 adapter 调用，不出现在 ToolInvocation、
  Runtime Assignment、Hands 参数、环境变量、Canonical Event 或 Tool Result。
- Action Digest 对工具名、版本和规范化参数做 SHA-256；审批校验同时绑定 tenant、Session、
  policy version 与有效期。
- Tool Gateway 对适配器超时返回 unknown side-effect，禁止把不确定外部效果当作安全重试。
- Artifact 对象以 SHA-256 寻址并在 tenant 内去重，Metadata/ACL 独立；下载令牌使用 HMAC，
  绑定 tenant、actor 与过期时间。
- Hands Process 只使用 `create_subprocess_exec`，不启用 Shell；取消与超时都会终止子进程。

## 已知边界

- 当前仓库提供本地 Hands、内存 Object Storage 与 InMemory Vault 适配器；生产对象存储、企业
  Vault、恶意内容扫描和具体 SaaS Connector 通过相同端口接入，不在仓库中保存真实 Secret。
- M4 的 Child DAG、Coordinator/Worker/Reviewer 权限和 Artifact 合并评审不属于 M3。
- Runtime Event Bus 仍只用于进度通知，不作为审批响应入口或结果交付保证。
