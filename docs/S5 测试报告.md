# S5 测试报告

## 范围

S5 将生产部署实现收敛为 Docker Compose：12 服务副本与资源边界、Secret 文件挂载、独立
数据库角色、一次性迁移进程、内部网络/统一 ingress、蓝绿发布、扩缩容和故障恢复。

## 自动化覆盖

- `test_s5_production_deployment.py`：Compose 解析、12 服务副本/资源/身份/角色、安全选项、
  唯一入口、最小 Secret 分发、secret-file loader 与迁移发现。
- `scripts/compose_preflight.py`：不可变镜像、必填配置、独立角色 DSN、唯一高熵 workload
  token/lease key 与 Compose 解析的部署前 fail-fast 门禁。
- `test_postgres_s5_migration_runner.py`：真实临时 PostgreSQL 上的首次并发迁移、advisory
  lock、幂等重跑、checksum drift。
- S1–S4、M5–M8 测试继续覆盖版本化内部契约、完整任务链路、SSE replay、Delivery
  retry/DLQ/redrive、Projection rebuild、Retention、审计、owner kill 后 claim/lease
  接管、SeaweedFS、Vault、Kafka 和数据库角色边界。
