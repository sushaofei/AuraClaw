## 已验证

- 4 个 Projection/Orchestrator/Runtime 副本处理 200 个 Session：Projection 版本均为 `[1, 2]`、
  Runnable 与 Assignment 无重复、任务分布到 4 个 Runtime。
- 真实 PostgreSQL 双 Orchestrator 竞争只生成一个 Assignment；生产调度由 Session Runnable Outbox
  驱动，不扫描完整 Event Log。
- Runtime 在四个故障注入点由不同实例从 checkpoint 恢复；新 fencing 单调递增，旧实例的 Session、
  Tool 与 checkpoint 写入被拒绝，Model/Tool 幂等调用各执行一次。
- Projection 双 Worker 保持同 Session 顺序；Delivery 双 Worker 按 Session/Sink 串行，claim 过期、
  retry、Store 重启和后续 Job 均恢复成功。
- Streaming 双实例共享 sequence/replay/connection；Hands 原子选主；Model 调用/配额、Policy bundle、
  Credential revoke/usage、Artifact finalize/scan/GC 均通过双实例或重启恢复测试。
- 真实 SeaweedFS multipart/finalize/download/SHA-256 scan、响应丢失恢复和双副本 GC 通过；真实 Vault
  readiness 与显式 `password` 字段 resolve 通过，未输出 Secret 值。
- `0010`～`0014` 在临时 PostgreSQL 完成 up/down roundtrip；既有 S3 migration roundtrip 的迁移
  选择器已收紧为明确的 `0001`～`0008`，避免未来迁移被误选。
- Ruff、Mypy（145 个源码文件）、10 条 import-linter、Compose config、Release Gate 与 Secret Scan
  全部通过；95 项 unit tests 全部通过。
