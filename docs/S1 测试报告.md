## 安全与迁移结论

- HTTP 服务身份可由 Bearer workload token 映射，且必须与 DTO 中的 service identity 一致。
- Runtime 配置契约禁止额外 Provider Secret 字段；Hands Tool arguments 无法覆盖 tenant、run、
  lease、fencing 或 Runtime identity。
- SeaweedFS Access/Secret Key 使用 `SecretStr`，未读取、打印或提交真实 `.env`。
- S1 不创建业务 schema；Hands Invocation、Policy、Credential Audit、Artifact Metadata 的物理
  schema、角色与迁移在 Issue 计划的 S3 实现。
- S1 可通过切换 composition 回滚到 in-process adapter；Session allowlist、Lease/Fencing 和
  Secret 隔离红线不得回滚。
